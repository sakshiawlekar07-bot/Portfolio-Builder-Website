# Portfolio Builder Website

## About the Project

Portfolio Builder is a website that allows users to create and customize their personal portfolios using different templates. It provides an easy way to build and manage a professional online portfolio.

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL

## Features

- User Registration and Login
- User Dashboard
- Multiple Portfolio Templates
- Portfolio Builder and Editor
- Profile Management
- My Portfolios
- Image Upload
- Contact Form
- Portfolio Preview and Download
- About and FAQ Sections
